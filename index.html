🎹 StageKeys Web

Una base para tocar muestras de tus conciertos de MainStage desde el celular o conectar un teclado MIDI compatible.

1 · Importar concierto o muestras

Selecciona una copia ZIP del paquete .concert o audios sueltos. El navegador buscará WAV, MP3, M4A, AIFF y OGG. Para abrir un paquete .concert, comprime una copia desde Finder en tu Mac. Si el teléfono no permite elegir ZIP, extrae el paquete en una computadora y carga los WAV directamente.

Esperando archivos.

2 · Conectar teclado físico por MIDI

Conecta el teclado al celular con un adaptador USB OTG compatible. En Android, el navegador puede recibir MIDI solo si admite Web MIDI; Chrome suele ofrecer mejor compatibilidad. En iPhone/iPad, la compatibilidad web MIDI es limitada. Si el botón no detecta tu teclado, todavía puedes tocar las teclas de la pantalla.

No conectado

Nota: el teclado físico envía notas MIDI, pero para sonar necesita una muestra cargada en esta página. No todos los celulares, adaptadores o navegadores admiten MIDI USB.

3 · Tocar

La página transpone la muestra seleccionada para otras notas. Es útil para probar sonidos, pero una sola muestra no reproduce un instrumento multisample con timbre natural en todo el teclado. En computadora: A W S E D F T G Y H U J K.

Importante sobre archivos MainStage

Un archivo .concert no es un formato de audio universal: guarda patches, instrumentos, mapeos, efectos, controles y ruteo de MainStage. Esta web no puede ejecutar el concierto original de forma idéntica ni convertir automáticamente archivos .exs/.sxt, efectos o ajustes. Sí puede leer audio compatible incluido en el paquete y tocarlo. Para lograr un resultado parecido al original, hay que reconstruir cada patch, asignar sus muestras y recrear efectos. Los archivos se procesan localmente en el navegador; no se envían a un servidor.
